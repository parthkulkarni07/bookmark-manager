# 🔖 Bookmark Manager

My second web development project, built using HTML5 and CSS3.

## 📌 About the Project
Bookmark Manager is a simple webpage that organizes useful website links into Primary and Secondary Bookmarks for easy access.

## ✨ Features
- Primary Bookmarks
- Secondary Bookmarks
- Opens links in a new tab
- Simple and clean layout

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
- `index.html` – Main webpage
- `style.css` – Styling and design
- `README.md` – Project documentation
